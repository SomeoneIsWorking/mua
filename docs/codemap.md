# Codemap

MUA is the title layer above `xenon-host` and `alchemy`. The current core gap is
the first native guest entry: media identity and executable feasibility are
measured, the shared Xenon module ABI is compiled, and the exact Gold profile is
generated from one title authority. The real generated function/import bridge
does not exist yet.

| Status | Meaning |
|---|---|
| **real** | Implemented and verified on the supplied exact build. |
| **partial** | Implemented with the named gap. |
| **planned** | Ownership is fixed but no shipping implementation exists. |
| **absent** | Not implemented. |

## Subsystems

| Subsystem | Status | Where | Gap / next |
|---|---|---|---|
| Exact title identity | **real** | `config/mua.toml` | Wire shared disc/XEX verifier into the launcher; unknown revisions must refuse. |
| Platform choice | **real** | `docs/RE/platform-selection.md` | Xbox 360 Gold is primary; PS2 is an auxiliary engine reference. |
| Headless execution observation | **real** | `docs/RE/platform-selection.md` | Reaches retail main menu. Validate Xenia as a MUA oracle before differential claims. |
| Shared Xenon host | **partial** | peer `shared/xenon-host` | Exact module/import/capability validation is synthetic-verified and consumed here; real guest memory, kernel, graphics, audio, storage, and input capabilities remain absent. |
| Shared Alchemy engine | **partial** | peer `shared/alchemy` | Full PS2/Xbox 360 archive traversal and PS2 RGBA5551/CLUT8 decoding are real; MUA executable ARK/input ABI plus mesh/animation/audio semantics remain unverified. |
| Generated PPC module | **absent** | ignored `scratch/titles/<sha>/ppc/` | Fix 13 instructions, classify 82 targets, generate without hand edits. |
| Exact compiled profile | **real** | `config/mua.toml`, `tools/generate_profile.py`, `src/title/title_profile.cpp` | One TOML authority generates the Xenon `ImageIdentity`; explicit disc provisioning still needs to verify the supplied bytes against it. |
| MUA title adapter | **partial** | `include/mua/title_profile.hpp`, `src/title/title_profile.cpp` | Exact identity is compiled; real `GuestModule`, import manifest/bindings, overrides, save namespace, and probes remain absent. |
| Host composition | **planned** | `src/app/` | Compose one module + one title adapter with `xenon-host`. |
| Differential harness | **absent** | `tools/`, `tests/` | Establish deterministic Xenia state/frame boundary and positive/negative controls. |
| Native renderer/audio/input | **absent** | shared host + MUA Alchemy delegate | Reach first missing service before growing subsystems. |
